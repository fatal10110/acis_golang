# Agent rules

The rules for this repository live in `AGENTS.md` (and `CLAUDE.md`) at the root of the outer
`acis_public/` workspace that contains this checkout next to `aCis_gameserver/` and `aCis_datapack/`.
Launch agents from that workspace root and read that file first. Scoped guides stay in
[`docs/agents/`](docs/agents/); package rules in
[`internal/gameserver/network/AGENTS.md`](internal/gameserver/network/AGENTS.md).
